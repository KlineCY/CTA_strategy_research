# CTA多资产多空策略研究

本项目以37只美国上市ETF代表六类市场，研究动量、趋势与波动率信息能否改善未来五个交易日的收益预测，并将预测转化为受约束的多空持仓。研究链路连接行情与标签、信号构造、逐月模型训练、验证期选择、五日重叠持仓和扣费账户。仓库提供源码、研究入口及汇总结果；原始行情、市场指数和利率文件由运行者在本地提供。

## 研究对象与方法

37只ETF覆盖美国宽基股票、美国行业股票、国际股票、固定收益、商品和另类资产。ETF价格收益是本项目的观察对象，回测结果不代表期货合约交易。原始样本覆盖1630个市场交易日，其中12日存在部分资产缺价。数据加载保留市场日历，拆分调整仅在内存中完成；某资产若缺少完整五日窗口，其历史持仓被排除，其他有完整窗口的资产继续参与。完整窗口判断使用事后行情，因此回测中的这项筛选属于历史研究口径。

六项模型特征为MOM、MOMRA、CSMOM、MACD、平滑MACD和VIX／MOVE波动率状态。每个预测月仅使用当时已成熟的五日标签，先选择MACD参数，再按三个月拟合、一个月局部验证、一个月预测的顺序比较七类模型：LASSO、Ridge、Elastic Net、Decision Tree、Random Forest、XGBoost和六项特征等权合成模型。资产特征经过历史缩尾、横截面归一化及训练窗标准化；波动率状态的横截面归一化口径与保留指数历史分位数的口径在共同Validation样本上比较。

模型层先按Validation的MSE与MAE筛选预测误差接近最优的候选，组合层随后对每类模型的14×14组风险与换手惩罚参数进行同口径评估。最大回撤不超过15％的候选按扣费后几何年化收益优先、回撤第二排序。最终入选Ridge，组合参数为`λ=0.005`、`γ=0.0025`。优化器决定各ETF的多空方向和目标权重；每批五日持仓约束单资产权重为−10％至＋20％、净敞口90％至100％、总敞口280％至300％。五批重叠后的账户实际敞口单独统计。Ledoit–Wolf训练窗残差协方差用于主线组合；滚动样本外残差协方差用于同决策日敏感性分析。VIX／MOVE状态与历史组合波动率构成缩仓候选，Validation选出的方案是不额外缩仓的基础组合。

## 历史结果

|阶段|入选模型|扣费后几何年化收益率|年化波动率|最大回撤|EFFR现金基准Sharpe比率|
|---|---|---:|---:|---:|---:|
|Validation|Ridge|28.07％|16.15％|10.65％|1.32|
|历史Test|Ridge|31.20％|16.57％|6.88％|1.48|

表中为完整阶段的ETF价格回测，依据仓库中的[三阶段最终选定账户表现](results/三阶段最终选定账户表现.csv)。从首笔成交日计算的历史Test有效交易期，策略几何年化收益率为31.30％；同日起37只ETF等权买入并持有基准为21.09％。两者均计入同一佣金代理，基准另计期末卖出费用。Training的逐月预测只使用历史信息，但其组合参数由后续Validation选定，Training账户收益仅作为事后参数诊断。

账户计入成交佣金及卖出端Section 31费用；分红、融资、借券费和滑点未进入现金账本。五日完整窗口的缺价筛选具有事后信息，结果应解释为指定数据和费用口径下的历史研究结果。绩效数值来自已完成的内部全量运行；本仓库未分发原始输入，重新计算需提供具有使用权且符合[输入格式](data/INPUTS.md)的数据。

## 代码与运行

`src/cta_project/`包含数据、特征、模型、组合、风险与报告模块；[研究Notebook](notebooks/research_pipeline.ipynb)按研究顺序展示各阶段输出。[研究设计](docs/ARCHITECTURE.md)说明目标、时间边界、优化器与结果解释；[数据与费用依据](docs/PROVENANCE.md)记录输入和费用口径；[测试与复现](docs/TEST_REPORT.md)说明可执行检查及历史结果边界。

在工程根目录安装依赖后，运行者将37只ETF行情、资产清单、VIX、MOVE及EFFR共41个输入文件放入`data/raw/`，再执行：

```powershell
python -m pip install -e ".[dev]"
python -m cta_project.cli validate-data
python -m pytest -q
python -m cta_project.cli smoke
python -m cta_project.cli run --workers 4
```

最后一步执行逐月模型训练及组合参数搜索，耗时取决于计算环境。相同输入、源码、参数和依赖版本会产生同一运行指纹，并允许复用已完成批次。Notebook可从工程根目录或`notebooks/`打开。历史汇总CSV用于阅读既有研究结果；提供本地数据后重新运行时，应使用独立的结果目录或先将仓库汇总表另存，以免与新结果混淆。
